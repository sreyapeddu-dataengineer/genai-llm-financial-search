# GenAI LLM Search & Summarization — Financial Filings & News Pipeline

A generative AI data pipeline that parses, cleanses, chunks and embeds unstructured financial filings and news corpora, then loads vector databases for retrieval-augmented generation. It powers LLM-based search and summarization over global markets content, with the same production patterns used for market data at scale. All filings, news and data are synthetic.

**Tech stack:** Python • PySpark • Generative AI • LLM Integration • Embeddings • Vector Databases • RAG

## Architecture Overview
Financial filings / news corpora → parse & cleanse → chunking → embeddings → vector database → LLM retrieval for search and summarization.

## Project Structure
`ingest/, parsing/, chunking/, embeddings/, vector_store/, search/`

## How to Run
Add synthetic sample filings/news to ingest/, run parsing and chunking, generate embeddings, load the vector store, then run a sample LLM search / summarization query.

## Skills Demonstrated
Generative AI, LLM Integration, Retrieval-Augmented Generation (RAG), Embeddings, Vector Databases, Python, PySpark, Apache Spark, Document Parsing & Chunking, Data Cleansing, REST APIs

## Notes
Portfolio project built on **synthetic data only** — real production engineering patterns from healthcare and financial services data engineering, with no real patient, customer, or market data, and no employer-confidential code or data.
